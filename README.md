# Habit Tracker

Welcome to **habit-tracker** - a lightweight, easy-to-use web application designed to help you stay consistent with your daily routines. Built with simplicity in mind, it gives you a clean interface to track your goals without any unnecessary clutter.

*(Plus, it includes a classic Snake game for when you need a quick study or work break!)*

---

## Why Use This?

We all know how hard it can be to build new habits. Whether you're trying to drink more water, read every day, or practice coding, having a simple visual tracker keeps you accountable. This project runs entirely in your browser using standard web technologies.

---

## Features

* **Clean & Simple Interface:** Focused on usability so you can track your daily progress without distraction.
* **Vanilla Web Technologies:** Powered directly by HTML (`index.html`), CSS (`styles.css`), and JavaScript (`app.js`).
* **Built-in Mini-Game:** Includes a classic Snake game script (`snake.js`).
* **No Heavy Dependencies:** Works straight out of the box without complex frameworks, servers, or installation steps.
